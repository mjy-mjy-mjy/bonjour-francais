# SKILL-01：可复用课程维护流程

- 来源：用户要求将“补充一课”和“整理”做成可复用Skill；采用两个独立入口，共用维护约定。
- 状态：完成（仓库文件与静态校验）；执行窗口：本云环境主会话；分支work；开工基线076e7e7，与origin/main核对一致，开工工作区干净。
- 范围：`.agents/skills/francais-add-lesson/`、`.agents/skills/francais-review-unit/`、共用维护流程及协作／计划／进度入口。
- 非目标：不实际新增课程、整理单元、迁移K2正文或修改个人学习状态；不安装账号全局Skill。

## 已交付

1. `francais-add-lesson`：资料核对、本课内容、共享知识增量、稳定技能关联、课程验证与交接。
2. `francais-review-unit`：指定范围跨课盘点、重复／遗漏修正、来源与依赖核对、明确未迁移项。
3. [共用维护流程](../MAINTENANCE_WORKFLOW.md)：作者源、稳定ID、覆盖扩展、旧记录、检查和提交约定。包含直接读取SKILL.md的跨客户端用法。
4. 两个Skill均有标准name／description元数据和可选显示配置，路径与AGENTS、README、计划互相可达。保护现在时范围、旧兼容基线与用户学习状态。

## 验证与限制

- 检查SKILL.md和显示配置的元数据、名称对应、文件路径、文档链接、示例与检查脚本存在性，`git diff --check`通过。
- 按纯文档范围不运行课程构建、应用测试或浏览器回归；没有产生新应用验证结论。
- 当前会话的技能目录未自动刷新，未验证客户端选择器发现或真实调用执行。新会话能否显示以客户端发现机制为准，直接读取SKILL.md的入口已提供。
- 提交／推送按仓库约定执行，实际SHA以Git历史为准；不把Skill文件交付记为网站或账号全局功能已上线。
- 下一项K2-01仍待开始；学习状态不变。以后由用户指定课号或整理范围后调用。
