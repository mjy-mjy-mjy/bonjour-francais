# GOAL-01 · NCLC 7 目标看板

2026-11-18（北京时间），目标页窗口在 main 基线 `cdafd36` 上实施。用户确认首版用于现有法语项目，数据保存在当前浏览器。入口为 `#goal`，可从首页或侧栏打开。

- 学时条从左向右累积。可编辑目标与累计学时，快捷增加 1 或 2 小时，或按整分钟记入，并撤销最近一次新增记录。
- 时间条固定右端，从开始日到截止日逐渐缩短。按本地日历显示剩余天数，截止日当天为零。首次使用的初值为 1,000 小时、已学零小时，截止日由使用者选择。
- 学时与日期使用独立的本地存储键，课程备份不含此键。多标签页写入前读取最新记录，支持 Web Locks 的浏览器串行更新。
- 修改范围为首页模板、导航和路由、目标页资源、资源指纹与针对性回归测试。阶段计算与跨设备同步留待后续讨论。
