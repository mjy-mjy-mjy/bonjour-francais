# 知识技能树：首版实现与后续方案

用户已于2026-10-29确认开始实现。首版入口为 `#skills`；本文区分已实现范围与后续扩展。

## 用户要解决的问题

用户希望像《赛博朋克2077》的角色成长、英雄联盟的天赋系统一样，在一页看到法语知识体系、自己的位置与逐个点亮的技能。地理地图和教材目录不能替代知识结构。

保留两个互通的视图：大陆展示教材旅程；技能树展示能力成长。课程与知识是多对多关系，同一知识跨课出现时只维护一个语义节点。当前 `knowledgeMastery` 是课内章节自评，不能直接当成已完成的共享知识树。

## 页面提案

- 全屏技能面板：上方显示目标、已点亮节点、待复习节点和建议下一步；中心展示分支及连线；右侧是选中节点详情。
- 总览先显示分支和阶段。放大或展开分支后，显示具体技能节点，避免一屏塞满无法阅读的数百个小字。
- 主分支：语音、词汇、语法、听力、口语、阅读、写作。动词变位／时态作为语法的高频子树，提供直接入口。
- A1／A2／B1／B2 是查看学习阶段的维度；同一知识可以在多个阶段深化，不机械地把所有节点排成一条不可跳过的课程链。
- 深色墨蓝背景、金属边框、金色点亮和细线连接，采用角色技能面板的视觉结构；地理大陆保留现有羊皮纸画风。

## 节点与连线

例子：动词与时态 → 复合过去时 → avoir／être助动词、常用过去分词、否定与疑问形式、être分词配合。这些是真正的学习技能；第18、19课是它们的课程出处。

每个节点显示名称、状态、建议基础。点击后可查看：能做什么、相关规则、关联课程、掌握标准、自评与复习记录。连线表示学习依赖或建议顺序，不等于强制锁住后续内容。

建议状态：未学习（灰）、已接触（铜）、能独立运用（金）、复测巩固（亮金并加标记）。文字和图形同时表示状态，不能只靠颜色。

“已接触”可以引用课程完成记录作为线索；独立运用和复测不能由看完课程、学习时长、点击次数自动推断。旧章节自评只能作为参考，不能无条件迁移成整个语义技能已掌握。

## 进度含义

- 分别显示已接触和已掌握节点数量，按分支查看短板。
- 数量分母必须是明确收录的技能集合，不能把“收录的A1知识已完成”写成“整个法语已掌握”。
- A2—B2 尚无内容的节点明确标为规划，未收录不等于用户不会。
- NCLC7 是听说读写四项考试目标。树上的学习进度与考试准备／成绩分别记录，不能凭树亮满自动判定达标。

## 首版已实现（2026-10-29）

- 七个分支、A1—B2全景、阶段筛选、分支筛选和技能搜索。桌面全景以七列展示，窄屏减少列数并保持可拖动探索。
- 64个A1语义技能取自现有第1—20课；每个有稳定ID、学习目标、两项掌握标准、原讲义链接和建议基础。同一个技能可以链接多课，例如地点代词y链接第10、19、20课。
- 语法按动词与时态、冠词与修饰、句型与代词展开，展示依赖连线。其他分支直接展开技能。
- A2—B2共21个方向节点明确标为规划，无掌握按钮、不计入进度。
- `skillMastery` 独立于课程完成和旧章节自评。0未学习、1已接触、2能独立运用、3复测巩固；2与3由用户自评。记录2后至少24小时才开放复测标记，并保存掌握／复测时间。
- 运用记录可保存例句、错误和复测结果；状态、记录随原学习备份导出／导入，旧备份兼容。未知但格式兼容的语义ID保留，便于后续扩展。
- 全局和分支计数、待复测数量与建议下一步；建议依赖已记录的技能基础，优先考虑已接触／相关课程已完成的技能，不强制锁住查看权限。
- 课程页、地图和导航均可进入技能树；课程页显示关联技能和当前点亮标记。浏览树不改写课程完成记录。
- 画布可拖动、滚轮／双指缩放、键盘移动与缩放、全景适配。页面独立于书房配色；详情独立布局，窄屏位于画布下方。

## 内容与记录约定

- `knowledge/skills.json` 是唯一手工维护的技能索引源；`scripts/build-skills.py` 生成 `skill-tree-data.js`。课程规则与例句仍由原讲义维护，技能树只维护语义索引、标准和关系。
- `scripts/build-course.py` 同时构建技能索引并更新资源指纹。运行全部 `scripts/*.test.cjs` 验证引用、DAG、统计、路由、保存回滚和备份兼容。
- 状态是个人自评，复测时间门槛不等于自动验收；当前没有自动评分、作品验证或考试预测。
- 当前64个技能不等于A1全部知识。无记录不代表用户在现实中没有学过，初次使用请自行确认已掌握的节点。
- 个性化数据仍保存在当前浏览器；跨设备需导出／导入备份。

## 后续扩展

1. 随学习逐步补充A1覆盖，细化适合独立复习的技能；保留现有稳定ID和跨课引用。
2. 把A2—B2方向展开为有实际教材、标准和内容来源的节点，再纳入对应阶段进度。
3. 按需要接入独立运用任务、证据与更细的复习计划，不将自评冒充测试结果。
4. 考试准备在用户进入备考阶段后展开，按真实四项成绩核对NCLC目标。
