# 知识技能树方案（待用户确认，尚未实现）

## 用户要解决的问题

用户希望像《赛博朋克2077》的角色成长、英雄联盟的天赋系统一样，在一页看到法语知识体系、自己的位置与逐个点亮的技能。地理地图和教材目录不能替代知识结构。

保留两个互通的视图：大陆展示教材旅程；技能树展示能力成长。课程与知识是多对多关系，同一知识跨课出现时只维护一个语义节点。当前 `knowledgeMastery` 是课内章节自评，不能直接当成已完成的共享知识树。

## 页面提案

- 全屏技能面板：上方显示目标、已点亮节点、待复习节点和建议下一步；中心展示分支及连线；右侧是选中节点详情。
- 总览先显示分支和阶段。放大或展开分支后，显示具体技能节点，避免一屏塞满无法阅读的数百个小字。
- 主分支：语音、词汇、语法、听力、口语、阅读、写作。动词变位／时态作为语法的高频子树，提供直接入口。
- A1／A2／B1／B2 是查看学习阶段的维度；同一知识可以在多个阶段深化，不机械地把所有节点排成一条不可跳过的课程链。
- 深色墨蓝背景、金属边框、金色点亮和细线连接，采用角色技能面板的视觉结构；地理大陆保留现有羊皮纸画风。

## 节点与连线

例子：动词与时态 → 复合过去时 → avoir／être助动词、常用过去分词、否定与疑问形式、être分词配合。这些是真正的学习技能；第18、19课是它们的课程出处。

每个节点显示名称、状态、建议基础。点击后可查看：能做什么、相关规则、关联课程、掌握标准、自评与复习记录。连线表示学习依赖或建议顺序，不等于强制锁住后续内容。

建议状态：未学习（灰）、已接触（铜）、能独立运用（金）、复测巩固（亮金并加标记）。文字和图形同时表示状态，不能只靠颜色。

“已接触”可以引用课程完成记录作为线索；独立运用和复测不能由看完课程、学习时长、点击次数自动推断。旧章节自评只能作为参考，不能无条件迁移成整个语义技能已掌握。

## 进度含义

- 分别显示已接触和已掌握节点数量，按分支查看短板。
- 数量分母必须是明确收录的技能集合，不能把“收录的A1知识已完成”写成“整个法语已掌握”。
- A2—B2 尚无内容的节点明确标为规划，未收录不等于用户不会。
- NCLC7 是听说读写四项考试目标。树上的学习进度与考试准备／成绩分别记录，不能凭树亮满自动判定达标。

## 实施顺序建议

1. 用真实A1内容盘点语义知识和课程引用，挑选冠词、现在时、复合过去时做完整分支样例；保留现有讲义入口。
2. 先给用户看包含整体结构和完整样例的技能面板，再确认视觉和点亮规则。
3. 在统一知识源上实现节点记录、备份兼容、跨页面联动，逐批补齐A1；后续再纳入A2—B2。
4. 考试任务在备考阶段接入；本方案不提前创建虚构题库或自动评分。
