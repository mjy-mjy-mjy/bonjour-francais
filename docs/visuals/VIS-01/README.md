## 可重复运行

环境需已有Python Playwright和Chromium；这是可选开发检查，无站点运行依赖，也不加入Pages CI。先在仓库根目录启动 `python3 -m http.server 8765 --bind 127.0.0.1`，再运行 `python3 scripts/check-verb-view.py`。脚本会刷新新版截图和 [browser-report.json](browser-report.json)，原版对照图保留。

检查覆盖：

- 五组桌面视口、页面宽度、画布与详情独立布局、节点可见范围、选中关系数量。
- 深链接、重音兼容搜索／无结果、选择结果、前进后退、Esc关闭。
- 点亮与运用记录保存／刷新，24小时复测门槛未到时禁用，导出／导入及缺少新字段的旧备份导入。
- 跨分支后续技能、原课程跳转、原课程关联技能入口。
- 键盘缩放／平移／复位、指针拖动、滚轮缩放、减少动态效果；浏览器pageerror无异常。

测试记录只在临时浏览器及临时备份文件中使用，未上传私人学习数据。截图均在写入测试状态前采集。浏览器导入检查等待持久化完成后才导航，避免异步文件读取竞态。
