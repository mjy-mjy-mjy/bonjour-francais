# Bonjour Français · 你好法语

网站 / 博客链接：[https://mjy-mjy-mjy.github.io/bonjour-francais/](https://mjy-mjy-mjy.github.io/bonjour-francais/)

## 第一版功能

- 按路线学习：课程目标、中文讲解、词汇、例句、练习与解析。
- 动态首页：记住最近打开的未完成课次；标记完成后推荐下一课，也可手动选择当前学习课次。
- 扁平分类：侧栏直达发音、词汇、语法、听力、口语、阅读与写作，并集中列出复习、官方资源与邀请记录。
- 阅读布局：优先展示继续学习与教材单元路线，采用中法文字体区分、清晰的正文、例句和练习层级。
- 配色切换：默认液态玻璃，可通过右上角按钮切换为米白与墨绿色的“纸感书房”；配色偏好保存在当前浏览器。
- 个人复习：学习进度、收藏、错题和笔记，保存在浏览器，支持导出与导入。
- 随手记：侧栏和顶部均有独立入口，随时记录词汇、句子和想法，支持草稿自动保存、多条记录、编辑、删除和搜索。
- 官方资源：NCLC 标准、加拿大 Express Entry 与语言成绩对照。
- EE 邀请记录：轮次编号、类别、官方日期时间、最低获邀 CRS 分数、邀请数量、同分排序规则及官方来源。

## 首页如何继续学习

第一次访问可从第1课开始，也可在首页“当前学习课次”选择你实际学到的课程。打开未完成课程或其技能页会记住课次；只打开课程不会标记完成。标记完成后推荐后续未完成课次，回看已完成课程不会替换当前课次。撤销完成会将该课恢复为当前课次。

首页标题、课程入口、课次高亮和默认技能入口随进度变化。第22课及以后的讲义尚未补充时，首页会明确显示“教材笔记”；技能入口指向就近已提供讲义的课程。记录仅保存在当前浏览器，旧备份仍可导入；旧记录没有当前课次时，根据已完成课次推荐，也可手动调整。

## 界面与配色

首页按“继续学习 → 教材单元 → 复习与分类”的顺序组织。9个单元均展示法语单元名称（如 UNITÉ 1 · Rencontres）和课次范围，可直接选择并查看对应4课的状态；浏览单元不会改变当前学习课次。前20课的完整讲义目录可展开，36课学习记录入口继续保留。

液态玻璃配色使用浅灰背景、蓝紫色光晕和半透明导航控件，课程正文采用清晰的实色面板。纸感书房配色使用米白、墨绿色与更简洁的边框。两套配色均随系统适配明暗外观；系统要求减少透明度时，导航不使用模糊效果。

“当前学习课次”保留原生下拉选择操作，箭头与右侧边框保持固定留白，长课名保留箭头空间。

导航与正文采用统一的20px栏间距，顶部工具栏、正文及页脚的起始位置对齐；较窄桌面使用180px导航，手机保留上下布局。右侧留白采用16—32px的响应式范围，避免把导航预留空隙与正文左边距叠加。

字体通过`--font-body`与`--font-display`统一维护：正文、例句、变位表、练习及笔记继承系统拉丁字体栈（Apple系统字体、Segoe UI、Roboto、Noto Sans、Helvetica Neue、Arial），中文由PingFang SC或Microsoft YaHei等回退；课程标题和展示性文字使用Georgia，回退到Times New Roman／Noto Serif及中文字体。无需外部字体下载，同一字号下实际字形随设备可用字体变化；字体不能声称是唯一的“最优法语字体”。选型参考[Bootstrap系统字体栈](https://getbootstrap.com/docs/5.3/content/reboot/#native-font-stack)、[Microsoft Segoe UI说明](https://learn.microsoft.com/en-us/typography/font-list/segoe-ui)与[Georgia说明](https://learn.microsoft.com/en-us/typography/font-list/georgia)。

页面背景连续铺满窗口，顶部不留异色色带。首页、课程、分类和记录页随可用宽度伸展，页脚与正文对齐；宽屏使用均匀的左右留白，手机上自动调整导航与分栏，较宽的表格在自身区域内横向滚动。内容较少时，页脚仍位于窗口底部。

切换配色不会重新加载课程，也不会清除已选答案、已展开解析或学习记录。配色偏好与学习进度分开保存，学习备份只包含进度、收藏、错题和笔记；导入备份不会覆盖配色偏好。

## 随手记

点击侧栏或顶部的“随手记”，无需打开课程就能记录。标题可选，输入时自动保存草稿；点击“保存记录”收进列表。草稿在切换页面或刷新后保留，编辑中的草稿也能继续修改。课后笔记与随手记分别保存，使用随手记不会改变当前学习课次或完成状态。

记录按最近更新时间排列，支持编辑、删除和按标题或内容查找；顶部搜索也能找到已保存的随手记。删除记录、清空草稿或用编辑内容替换未保存草稿时会确认。浏览器无法写入时显示未保存提示，并保留当前草稿供继续保存或导出。

随手记与草稿一并包含在“学习记录与备份”的导出文件中。旧版本备份仍可导入；导入会替换当前全部学习记录，旧备份不含随手记时会清空当前随手记，因此请先导出当前备份。所有记录仅保存在当前浏览器，无需登录，也不会上传。

已在Chrome核对新增、编辑、草稿刷新恢复、主题切换、搜索、删除确认和导出／导入操作，并验收手机触控及320—2560px、两套配色和明暗外观的176种页面组合。

## 实现方向

无第三方前端依赖的静态网站，可通过 GitHub Pages 发布。课程与公开邀请数据独立维护；个人学习记录不上传仓库。GitHub Actions 在更新代码、手动触发或定时运行时检查官方邀请记录，展示最近成功检查时间；抓取或校验失败时保留已有记录。定时任务计划在北京时间每天 10:17 运行，GitHub 可能延迟或暂停长期未活动仓库的定时任务。

## 在电脑上预览

在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:8765`。请使用本地服务器预览，避免直接打开 HTML 时浏览器阻止邀请数据读取。

## 发布到 GitHub Pages

使用 GitHub Free 时，将仓库设为 Public。在 Settings → Pages 中选择 GitHub Actions 作为发布来源，然后手动运行 “Update official records and publish website” 工作流。完成后从 Pages 设置或工作流结果取得网址。

工作流只发布 `index.html`、样式、课程脚本及 `data/` 中的公开数据，不发布个人备份文件。

## 持续补课与知识整理

仓库内提供两个维护Skill，详细规则见 [持续维护流程](docs/MAINTENANCE_WORKFLOW.md)：

- `$francais-add-lesson`：补充指定一课，同步增量维护共享知识和技能关联。
- `$francais-review-unit`：整理指定单元或课次范围，核对重复、遗漏、出处及技能依赖。

例如：“使用 $francais-add-lesson 补充第21课，资料如下……”或“使用 $francais-review-unit 整理第17—20课”。建议逐课补充、每单元整理；两个操作都不会自动将用户标为已完成或已掌握。

Skill位于 `.agents/skills/`，同步仓库后由支持的客户端发现。当前会话未刷新或其他模型不支持 `$` 调用时，直接要求读取对应目录的SKILL.md并执行；这不依赖账号全局安装。
